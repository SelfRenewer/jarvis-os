Телефон

Телефон заходит в Jarvis OS только по одноразовому QR-коду с этой страницы: код живёт 5 минут и срабатывает один раз. На этом Mac вход держит приложение Jarvis — ничего вводить не нужно.

Дома · Wi-Fi

…

Пока включено, Jarvis OS слушает домашнюю сеть на адресе этого Mac. macOS может спросить, разрешить ли node входящие подключения — разрешите.

Это обычный HTTP — только для своей Wi-Fi. Jarvis OS запоминает сеть, в которой вы включили вход, и сам закрывает его в любой другой (кафе, гости); вне дома — туннель.
